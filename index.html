Git hub Desktop

O Git Hub desktop é uma aplicaçao q realiza a ligaçao entre o VSC, Git e GitHub. Desta forma os comandos do git são feitos apenas com cliques sem precisar usar comandos. Alem disso, o git hub desktop realiza a sincronizaçao do repositorio local com o remoto.
